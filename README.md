# WhoEdited

Petit plugin WordPress qui ajoute une colonne triable « Dernière modif. » aux écrans d'administration Pages et Articles.

## Ce que ça fait

- Ajoute une colonne « Dernière modif. » dans les écrans Pages/Articles (wp-admin), triable comme les colonnes natives.
- Affiche la date de dernière modification et le nom du dernier éditeur (en gras/italique).
- Pastille de couleur indiquant la fraîcheur du contenu : rose si modifié dans les 7 derniers jours, gris sinon.

## Installation (plugin classique)

1. Copier le dossier `who-edited/` dans `wp-content/plugins/` (ou uploader le zip via `Extensions > Ajouter`).
2. Activer le plugin via `Extensions`.
3. Aller sur `Pages` ou `Articles` pour voir la nouvelle colonne.

## Compatibilité

- Compatible Polylang (sites multilingues).
- Version courante : 1.4.
